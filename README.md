# raw-node-os-info

A practice-focused Node.js project demonstrating core-level system information handling using raw `http` and `os` modules — no Express, no external dependencies.

This project showcases the ability to extract, format, and expose key system diagnostics like CPU details, memory usage, uptime, and networking information using only **vanilla Node.js**.

---

## 🧠 Purpose of the Project

This is a foundational project to:

- Deepen understanding of **Node.js core modules**, especially `os` and `http`.
- Learn to **create servers without Express** to gain low-level control.
- Gain confidence in building **developer-facing tools** using native capabilities.
- Explore real-world use cases where system info is valuable: monitoring tools, CLI utilities, desktop apps, etc.

---

## ⚙️ Technologies Used

- `http` – to build a raw HTTP server
- `os` – to fetch real-time system-level data
- `JSON.stringify()` – to serialize objects for browser-friendly display
